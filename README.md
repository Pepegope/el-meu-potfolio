# Portafolio Personal - Pepe González Pérez

Portafolio web profesional desarrollado para la asignatura de Aplicaciones Web (2º CFGM SMR) utilizando HTML5, CSS3, JavaScript y asistido con GitHub Copilot.

## Mejoras propias aplicadas sobre el diseño base
1. **Selector de modo claro y oscuro:** Botón interactivo en la barra de navegación que cambia el tema de la web y guarda la preferencia del usuario.
2. **Nueva paleta de colores tecnológica:** Ajuste de colores principales (tonos cian/esmeralda) asegurando buen contraste y legibilidad.
3. **Animaciones personalizadas:** Efecto suave de elevación y borde iluminado al pasar el ratón (hover) sobre las tarjetas de proyectos y habilidades.
